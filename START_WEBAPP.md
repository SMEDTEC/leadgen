# 🌐 Start the Web App

## Super Simple - Just 2 Steps!

### Step 1: Install
```bash
npm install
```

### Step 2: Launch Web App
```bash
npm run webapp
```

That's it! The app will open at **http://localhost:3000**

---

## What You'll See

A beautiful web interface with:
- ✅ Simple form to configure scraping
- ✅ Real-time progress updates
- ✅ View results in your browser
- ✅ Download as JSON or CSV
- ✅ No coding required!

---

## How to Use

1. **Open Browser**: Go to http://localhost:3000

2. **Fill Form**:
   - Add Shopify store URLs (or leave for auto-search)
   - Set max stores (start with 5)
   - Click "Start Scraping"

3. **Watch Progress**:
   - See real-time updates
   - View logs as it runs

4. **View Results**:
   - Click "View All Results"
   - Download JSON or CSV

## Troubleshooting

**Can't access localhost:3000**
- Make sure the webapp is running
- Check terminal for errors
- Try http://127.0.0.1:3000

**Port 3000 already in use**
- Something else is using port 3000
- Stop other apps or change port in webapp.js

**No results showing**
- Wait for scraping to complete
- Check logs in the webapp
- Try with specific store URLs

---
